# QUICKSTART — включить движок (для тебя, Мирзабек)

## Кратко
Пока ты спишь — работает **твой Мак**, не облачный ассистент. Чтобы Мак крутил ночной цикл,
нужна разовая настройка ~10 минут. Можешь сделать сегодня или завтра.

## Вариант A — настроить сейчас (≈10 минут) и уйти спать с работающим циклом
```bash
# 1. забрать код
git clone <твой-репозиторий> contenti   # или git pull, если уже есть
cd contenti

# 2. поставить Ollama (если ещё нет)
brew install ollama

# 3. one-command установка (поставит зависимости, модель, конфиги, проверит ядро)
bash contentos/setup_mac.sh

# 4. проверить, что движок генерит идею
cd contentos && python3 -m contentos idea "почему биткоин падает" --net instagram

# 5. (опц.) Telegram-уведомления: создай бота у @BotFather, затем
export CONTENTOS_TG_TOKEN=...     # токен бота
export CONTENTOS_TG_CHAT=...      # твой chat_id

# 6. включить ночной автозапуск (launchd) — шаблон в docs/07-setup-macos.md
```
После этого каждое утро движок сам соберёт тренды, сгенерит идеи и пришлёт их.
