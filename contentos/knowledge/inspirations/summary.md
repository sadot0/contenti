# Вдохновители — выжимка для агентов

Сжатые выводы по трём аккаунтам, которые вдохновляют автора. Полные отчёты — в
`data/<account>/report.md`. Эта выжимка подаётся агентам как контекст.

## @kirills_finance — финансовое образование (IB/PE)
- **Ниша**: инвестбанкинг, оценка компаний, корп. финансы; русскоязычная аудитория (казахстанские корни).
- **Формат-ядро**: КВИЗЫ («Сколько формул знаешь?») + бытовые аналогии + личные истории.
- **Что тянет охват**: квизы/тесты (само-проверка → комментарии). Топ ~154K просмотров.
- **Что даёт высокий ER, но низкий охват**: узкие разборы (valuation, M&A) — «для своих».
- **ER**: ~5.6% средний. Манера: talking-head/закадр + экранная графика.
- **Урок для нас**: интерактив (квиз) = охват; глубина = лояльность. Хук-вопрос в первой секунде.

## @klinkovprofessor — мейнстрим инвест-образование
- **Ниша**: инвестиции/экономика для широкой розничной аудитории СНГ/Россия. 278K подписчиков.
- **Фишка**: «ПРЕДМЕТ В КАДРЕ» (карта памяти SanDisk, Big Mac, часы) объясняет экономику.
- **Что тянет охват**: конкретные инвест-идеи + громкие цифры («$1000 → $40 000»). Топ ~166K.
- **ER**: 4–8% (ниже из-за массового холодного трафика). Тон: спокойный авторитет «профессора».
- **Урок для нас**: знакомый предмет как хук = мгновенная понятность. Дисклеймер «не финсовет».

## @nomoeyesclosed — кинематографичный крипто-триллер ⭐ ближе всего к нише автора
- **Ниша**: КРИПТО. Тёмные документалки/расследования (крах рынка, скамы, MEV/dust-атаки).
- **Формат**: кинонарратив + закадровый VO + плотный монтаж из стоков (НЕ talking-head).
- **Что тянет охват/ER**: драматичные расследования (топ 580K, ER 10%) и разборы безопасности
  (pig butchering, MEV — ER до 15%). Геймификация (квест на $500) — всплеск вовлечения.
- **ER**: экстремально высокий, 7–15%. Средний охват ~117K.
- **Урок для нас**: сильнейший нарратив + польза/драма = виральность в крипте. Но дорогой продакшен
  и copyright-риск чужих материалов.

## Общие выводы для крипто-ниши (старт паттернов виральности)
1. **Хук в первые 1–1.5 секунды решает охват** (вопрос / шок-факт / предмет в кадре).
2. **Интерактив и геймификация** (квиз, «угадай», квест) → комментарии и охват.
3. **Польза + драма/история** заходит лучше сухой теории.
4. **Безопасность/скамы** в крипте — двойная ценность (драма + защита) → репосты/сохранения.
5. **Один ролик — одна мысль**, один CTA, петля в конце для пересмотров.
6. Дисклеймер «не финсовет» обязателен.
