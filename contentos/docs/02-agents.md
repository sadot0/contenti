# 02 — Штат AI-агентов

Агент = модуль кода с ролью, системным промптом, входом/выходом и (опц.) инструментами.
Все вызывают сменный LLM-бэкенд (Ollama). Базовый класс — `contentos/agents/base.py`.

## Роли (стартовый штат)

### 1. PositioningAgent — «стратег бренда»
- **Зачем**: определяет ТВОЁ позиционирование, tone of voice, рубрики, отличие от вдохновителей.
- **Вход**: твой контент-анализ + анализ вдохновителей + рынок UZ.
- **Выход**: `knowledge/profile/positioning.md` (кто ты, для кого, чем отличаешься, рубрики).
- Запускается редко (при ребрендинге/ревизии).

### 2. TrendResearcherAgent — «аналитик рынка/трендов»
- **Зачем**: копает тренды и инфоповоды (крипто + Узбекистан), формирует список тем.
- **Вход**: новости/тренды (через web-search MCP или ручной фид) + ниша.
- **Выход**: `knowledge/trends/<date>.md` — темы-кандидаты с обоснованием.
- На старте — полуручной (ты подкидываешь источники), потом автоматизируем.

### 3. ViralityAnalystAgent — «аналитик виральности»
- **Зачем**: выводит паттерны «что залетает» по каждой соцсети на основе данных
  (твои метрики + вдохновители), оценивает потенциал готового сценария.
- **Вход**: метрики из `data/`, правила workspace.
- **Выход**: паттерны (`knowledge/<net>/virality-patterns.md`) + оценка ролика (score + риски).

### 4. ProducerAgent — «продюсер»
- **Зачем**: из темы + соцсети собирает бриф ролика (угол, цель, эмоция, длина, рубрика).
- **Вход**: тема, workspace-правила, позиционирование, паттерны виральности.
- **Выход**: бриф (json) для сценариста.

### 5. ScriptwriterAgent — «сценарист»
- **Зачем**: пишет сценарий по **7-блочной структуре** (см. `04-virality-framework.md`),
  в твоём голосе, на ру/уз.
- **Вход**: бриф продюсера, твой tone of voice.
- **Выход**: сценарий с блоками + тайминги + ремарки по съёмке.

### 6. PackagingAgent — «упаковщик / SMM»
- **Зачем**: хук (первые 1.5 сек), варианты заголовка, идея обложки/превью, хэштеги под UZ,
  описание/подпись.
- **Вход**: сценарий + workspace-правила.
- **Выход**: пакет публикации.

## Как они работают вместе
Orchestrator выстраивает их в пайплайн под конкретный workspace:
```
trend_researcher → producer → scriptwriter → packaging → virality_analyst
        (positioning подаётся контекстом во все шаги)
```

## Расширяемость (позже)
- `ThumbnailAgent` (генерация обложек — через image-модель).
- `EditorAgent` (раскадровка/монтажный лист).
- `RepurposeAgent` (адаптация одного ролика под другую соцсеть — но с учётом, что логика разная).
- `CommunityAgent` (ответы/комьюнити-менеджмент).
- `SelfImprovementAgent` — агент, который по запросу создаёт/улучшает «скилы» (промпты,
  правила workspace) на основе результатов. Ты просил это — закладываем как отдельную роль.

## Принцип «скилов»
Каждый агент опирается на «скилы» = переиспользуемые промпт-шаблоны и правила, лежащие в
`knowledge/` и `config/`. SelfImprovementAgent умеет предлагать новые скилы и править старые,
а человек (ты) их утверждает. Это и есть «AI, который понимает запрос и создаёт правильные скилы».
