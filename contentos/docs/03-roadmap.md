# 03 — Дорожная карта (по фазам)

Принцип: каждая фаза доводится до конца → аудит стыковок → следующая. Качество > скорость.

## Фаза 0 — Фундамент и понимание (этот сеанс) ✅ в процессе
- [x] Скачать + транскрибировать вдохновителей (large-v3) и сделать отчёты.
- [x] Скачать + транскрибировать твой контент.
- [x] Заложить структуру `contentos/`, план, архитектуру, роли агентов, фреймворк виральности.
- [x] Сменный LLM-бэкенд (Ollama по умолчанию), базовый агент, три workspace-каркаса.
- [x] Твой контент-анализ + позиционирование под рынок UZ.
- [ ] Закоммитить и запушить в ветку (чтобы не потерять — контейнер временный).

## Фаза 1 — Рабочее ядро на твоей машине (после подтверждения)
- [ ] Ты ставишь проект локально, указываешь модель Ollama (`ollama list`).
- [ ] Прогнать `PositioningAgent` и `ViralityAnalystAgent` на собранных данных → паттерны.
- [ ] Рабочий пайплайн Instagram: тема → бриф → сценарий (7 блоков) → упаковка.
- [ ] CLI: `contentos idea "<тема>" --net instagram` выдаёт готовый пакет.
- [ ] Аудит: качество сценариев на 5–10 темах, правка промптов/скилов.

## Фаза 2 — Данные и тренды
- [ ] Логин instaloader → выкачать всю историю (твою + вдохновителей), топ по просмотрам.
- [ ] yt-dlp → YouTube ролики/Shorts (если нужно отдельно от IG).
- [ ] `TrendResearcherAgent`: подключить источник трендов (web-search MCP или фид новостей UZ/крипто).
- [ ] Цикл обучения: ты публикуешь → заносим метрики → паттерны обновляются.

## Фаза 3 — Фронтенд (дашборд)
- [ ] FastAPI-обёртка над ядром.
- [ ] Next.js/React дашборд: лента идей, редактор сценариев, очередь, метрики, «здоровье движка».
- [ ] Три вкладки-пространства (IG/TikTok/YouTube) с независимой логикой.

## Фаза 4 — Расширение и продукт для других
- [ ] Доп. агенты (Thumbnail, Editor, Repurpose, Community, SelfImprovement).
- [ ] Мультипользовательский режим (профиль = отдельная база знаний).
- [ ] Упаковать как продукт (личный бренд / личное развитие).

## Что блокирует переход к следующим фазам
- Фаза 1 ← подтверждение идеи + имя локальной модели.
- Фаза 2 ← session-файл instaloader + (опц.) yt-dlp локально.
- Фаза 3 ← выбор фронтенд-стека.
