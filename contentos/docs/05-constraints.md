# 05 — Ограничения и честные ответы

## Окружение
- **Облачный временный контейнер.** Этот сеанс — не твоя машина. Контейнер стирается после
  простоя. Единственный способ сохранить работу — `git commit && git push`. Я это делаю.
- **«Работать неделю, пока сплю»** — невозможно в одном облачном сеансе. Реально: сильный
  объём за сеанс + push. Долгую автономную работу можно организовать у тебя локально
  (cron/скрипты), когда ядро готово.

## LLM
- **Anthropic API** — ключа нет, платить не хочешь. Поэтому рантайм продукта = **локальный Ollama**.
- **Ollama из облака недоступен** (он на твоём `localhost`). Здесь я не могу прогнать агентов.
  Код пишу корректно под Ollama; запуск и тесты — у тебя локально.
- **Сейчас движок анализа — это я (Claude в этом сеансе).** Я делаю анализ вручную и кладу в
  `knowledge/`. Продукт потом крутит это на Ollama.
- Нужно от тебя: `ollama list` → точное имя и размер модели. От этого зависит сложность промптов
  и реалистичные ожидания (7–14B модель ≠ облачный Claude; будем подгонять промпты/скилы).

## Instagram
- Анонимно — только ~12 последних постов (глубже 401). Для полной истории и «топа по просмотрам»
  нужна **авторизованная сессия**: `instaloader -l твой_логин` → передать session-файл.
- Для своего аккаунта это нормально. Для чужих — публичные данные, в рамках исследования;
  учитывай ToS Instagram при масштабировании.

## YouTube
- Нужен `yt-dlp` (в облаке нет; ставится локально). Страница канала — JS, обычный fetch не читает.
- Твои Shorts = перезалив из IG → контент уже есть. Отдельную YouTube-логику делаем, ролики
  выкачаем локально при необходимости.

## Про «MCP-сервера» и «перелить GitHub в MCP»
- **MCP-сервер** подключается в твоём Claude Code через `settings.json` (или флагами), а не
  «внутрь продукта». Это инструменты для МЕНЯ (ассистента), не рантайм твоего движка.
- Полезные MCP для этого проекта:
  - **GitHub MCP** — работа с репозиторием/issue/PR (уже доступен в этом сеансе).
  - **Filesystem MCP** — доступ к локальным файлам (когда работаешь локально).
  - **Web/Search MCP** — сбор трендов/новостей (для TrendResearcher).
- **«Перелить весь GitHub в MCP»** как операция не существует. Что реально полезно:
  переиспользовать готовые open-source решения (библиотеки) — это мы делаем через обычные
  зависимости (pip/npm), а не через MCP. Если найдём подходящий open-source кусок — подключим как
  зависимость и сошлёмся на источник.
